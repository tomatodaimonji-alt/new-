# 月影の遺跡 — Android APK v1.1

## シンプルなゲーム専用アプリ

- アプリを起動するとゲーム画面を全面表示します。
- 「HTML更新」「再読込」「前に戻す」「自動更新」などの**上部操作バーはすべて削除**しました。
- ゲーム本体はルートの `index.html` で、APKビルド時に `starter.html` として内蔵されます。
- AIサービス・AIモデル・AIネットワーク連携は搭載しません。ゲーム内の敵の簡単な移動ロジックはゲーム性として残しています。
- AndroidアプリIDは `jp.tsukacchi.moonruins`。以前の箱庭APKとは別アプリです。

## 更新

- 起動時に `https://raw.githubusercontent.com/tomatodaimonji-alt/new-/main/index.html` をHTTPS取得します。
- 新版があればローカルに保存し、**次回の起動時に自動反映**します。プレイ中の強制再起動はしません。
- オフライン時・通信失敗時・不正なHTMLの場合は保存済みHTMLを使います。
- 更新HTMLの上限は12MiB。最後の旧HTMLを内部バックアップに保持します（UIには復元ボタンはありません）。
- **リポジトリがPrivateの間はAPKから取得できません。** 自動更新を有効にするには公開配信が必要です。公開してよいのがHTMLのみなら、別の公開配信用リポジトリを使い、Javaコード内のUPDATE_URLも変更してください。GitHub連携ができても、APK自体がPrivateの認証を持つわけではありません。

## APKを入手

GitHubの `Actions` → 最新の成功した `Build Moon Ruins APK` → `moon-ruins-apk` をダウンロード。ZIPを展開し `app-debug.apk` をインストールします。

**注意:** GitHub Actionsのデバッグ署名はビルド間で変わる可能性があります。旧APKの上書きインストールが署名不一致で失敗した場合は、固定署名キーでのリリースビルドが必要です。アンインストールはアプリ内保存データが失われる可能性があるため、事前のバックアップが必要です。

実機での動作確認は別途必要です。
