# 灰緑の境界 — 横画面探索プロトタイプ

## ゲーム概要

『Project Zomboid』の探索感を参考にした、オリジナルの斜め見下ろし探索ゲーム試作。敵・戦闘なし。廃屋、森、道路を散策し、残された物資を見つける。

- 内部データは46×46タイル。描画は安定性を優先したCanvas 2Dの等角投影で、樹木・屋根・壁などを立体風に描画。**WebGLの3Dポリゴンモデルではなく2.5D方式**。
- 4つの建物。入口の正面で「調べる」で入室。室内では屋根を消し、物資を拾える。出口のそばで「調べる」で退出。
- 最大6つの物資を拾える。地図表示あり。スマホ横画面固定。大きな十字キーを長押しで移動。
- ネットワークやAIなしでゲーム本体はオフライン動作。
- 表示はCanvas、画面周辺の操作はHTML/CSS。テストはPlaywright Chromiumで起動・移動・地図・インタラクションを確認。
- `index.html` を更新すると既存の自動更新対応APKが次回起動時に取得する（起動して取得→再起動で反映）。リポジトリはPublic設定が必要。
- APK本体は `Actions` → `Build Moon Ruins APK` の成功runから `moon-ruins-apk` を取得。従来のAPKからの上書きインストールは署名により失敗する場合あり。

## 操作

左の十字キー: 長押し移動
右「調べる」/十字キー中央: 扉の出入り、アイテムを拾う
右「地図」: マップの表示切替
キーボード: 矢印/WASDで移動、Enter/Spaceで調べる、Mで地図

二本指で画面をピンチすると縮尺を変えられる。

## テスト

- ブラウザ: `tests/smoke.mjs`。PlaywrightによるCanvas描画・ボタン・操作確認
- Android: `.github/workflows/android-smoke.yml`。エミュレーター上の開始画面・開始後画面の比較
- APK: `.github/workflows/build-apk.yml`。

## 現在の制約

この試作はAI・敵・建築・セーブ機能をまだ搭載していません。景観はローポリ調の2.5Dイラスト表現で、実際の3Dモデルや写実的なPBRテクスチャは使用していません。
