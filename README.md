# 森の遺跡 — 淡彩タイル版

このリポジトリの旧『灰緑の境界』を完全に置き換えた、スマートフォン縦画面向けのオフラインHTML探索試作です。

## 最新の仕様
- 真上見下ろし96×96タイルの淡い草地・砂道・住宅地。地表タイル、木・石・低木・花を手続き生成。
- 白い石壁と複数の建物。四隅の壁タイルを省略せず、衝突判定にも反映。扉は指定された入口1マスだけ通行可能。
- ブロック体型のオリジナルキャラクター。方向表示、簡易歩行アニメーション。
- 縦画面の大きな十字キーを押しっぱなしで移動。中央で調べる／採集。周辺の木、石、木の実を取得。
- 上部の半透明パネルにHP・食料・時間・資材、右上に「新しい世界」。持ち物ウィンドウ。
- 全体はCanvas 2D。ネットワーク接続不要・外部ライブラリなし。敵なし・簡易採集のみ。

## 起動
`index.html` をブラウザで開いて操作できます。Android APKはGitHub Actionsの `Build Moon Ruins APK` から `moon-ruins-apk` を入手します。APKはポートレート固定で、WebView内に単一HTMLを埋め込んで起動します。

## テスト
`tests/smoke.mjs` と `.github/workflows/browser-test.yml` はPlaywrightを使用し、描画、十字キー長押し移動、すべての建物の四隅の壁、扉、UI、「新しい世界」を検証します。

`.github/workflows/android-smoke.yml` はAndroidエミュレーターのスクリーンショットを利用した追加の簡易操作テストです。

## 制限
写実的な3Dではなく、ユーザー提供の写真を参考にした色彩・配置の2D表現です。室内壁の細かな部屋分割、戦闘、NPCの生活行動、セーブはこの試作にはありません。
