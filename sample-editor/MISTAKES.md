# サンプルエディター 失敗・再発防止記録

同種の不具合は新しい項目を増やさず、該当項目を改善する。原因とチェック項目を主に残す。

| 分類 | 過去の問題 | 再発防止 |
| --- | --- | --- |
| WebGL床 | 道路/白線等がほぼ同じ高さでちらつく | 面の重なり/深度を確認し、接する面の高さを分ける |
| 遮蔽 | 主人公が建物の裏に入ると建物が消え、不自然だった | 建物を隠さない・透明化しない。不透明のまま描画し、主人公が隠れるのは許容 |
| 人物 | 箱形・前向きが分からない | 丸み、顔、進行方向の旋回を保護 |
| 操作の競合 | 左右の指を使うピンチ自動判定が左移動＋右視点まで奪い、同時操作が困難 | 開始時の左右領域で指の役割を固定。左移動と右視点は独立し、ズームは右側開始の2指だけ。混合ピンチ判定を再導入しない |
| 左パッド | 接触始点と表示位置が違う/終了時に戻らない | 触れた座標へ実物を移し、指終了・中断・画面非アクティブ時に復元 |
| 視点上下 | 空が見えない/地面下に潜る、上下スワイプが逆方向 | 指を上に滑らせると上を見る（pitch -= dy）、空の視認・上下限を検証 |
| 撮影カメラ | 縦枠だけ表示し実際の描画が横のままだと構図が合わない | WebGL viewport/scissorと投影比を9:16に同期し、探索時には元へ復元。保存済みカットの再生中は右視点入力を止める |\n| 配布版 | v表記・Gradle・Artifactsが一致しない | 3か所同期、生成スクリプトとCIテスト |
| 自動更新 | HTML以外を参照すると既存アプリが更新できない | 生成成果物は単一HTML、オンライン失敗時は現行ファイル維持 |
| 足音 | 三角波の下降音が電子音っぽく不自然 | 短いノイズの接地音、低域フィルタ、左右の微差、歩幅と発音間隔を合わせる |
| 店舗の通行 | コンビニの建物全体を当たり判定にすると入口から入れない／見えない壁ができる | 壁は周囲だけ、入口は開口、什器はID付きの実体座標で衝突。通路の通行テストを行う |\n| 街の独立性 | 建物座標が描画・衝突に分散すると1軒の移動でずれる | ID付きsceneデータを共有し、対象バッファ更新・衝突追従・ローカル保存を確認 |\n| 主人公の立体感・歩行 | 箱/球の積み上げや関節の単純往復では地面を滑り、膝の動きが不自然 | 人体輪郭を優先し肩・膝の球状継ぎ目を抑える。左右位相差、接地/遊脚、膝IK、歩幅と停止補間を検査。靴の接地影は半透明描画を局所化 |\n| コード肥大化 | 1 HTMLに全ロジックが混在 | ソースモジュールを分割、配布時のみ結合、既存関数改修優先 |

## 検証チェック（改修ごと）
- vがテンプレ/Android/Artifactと一致し、生成HTMLが最新
- 左タッチ移動と右タッチ視点が同時にできる
- 右2指ズーム中も左の入力を誤ってキャンセルしない
- パッドの復帰/カメラ上方向/街の衝突と遮蔽/音を確認
- 連続起動、自動更新、オフライン、WebViewでの描画を確認（実機未検証の場合は明記）
