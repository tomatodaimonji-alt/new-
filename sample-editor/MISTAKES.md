# サンプルエディター 失敗・再発防止記録

同種の不具合は新しい項目を増やさず、該当項目を改善する。原因とチェック項目を主に残す。

| 分類 | 過去の問題 | 再発防止 |
| --- | --- | --- |
| WebGL床 | 道路/白線等がほぼ同じ高さでちらつく | 面の重なり/深度を確認し、接する面の高さを分ける |
| 遮蔽 | カメラ手前の建物が人物を隠す | 建物個別描画、プレイヤーとの遮蔽判定を継続 |
| 人物 | 箱形・前向きが分からない | 丸み、顔、進行方向の旋回を保護 |
| 操作の競合 | 2本指で左パッドが解除される、または視点が操作できない | 左移動+右視点は同時操作、2つのカメラ指だけピンチ |
| 左パッド | 接触始点と表示位置が違う/終了時に戻らない | 触れた座標へ実物を移し、指終了・中断・画面非アクティブ時に復元 |
| 視点上下 | 空が見えない/地面下に潜る | 自由な上方向とカメラ位置の両立、pitch上下限のチェック |
| 配布版 | v表記・Gradle・Artifactsが一致しない | 3か所同期、生成スクリプトとCIテスト |
| 自動更新 | HTML以外を参照すると既存アプリが更新できない | 生成成果物は単一HTML、オンライン失敗時は現行ファイル維持 |
| コード肥大化 | 1 HTMLに全ロジックが混在 | ソースモジュールを分割、配布時のみ結合、既存関数改修優先 |

## 検証チェック（改修ごと）
- vがテンプレ/Android/Artifactと一致し、生成HTMLが最新
- 左タッチ移動と右タッチ視点が同時にできる
- 右2指ズーム中も左の入力を誤ってキャンセルしない
- パッドの復帰/カメラ上方向/街の衝突と遮蔽/音を確認
- 連続起動、自動更新、オフライン、WebViewでの描画を確認（実機未検証の場合は明記）
