# PINE 更新履歴

## 2026-11-17 — 開発基盤の整理（機能変更なし）
- `forest-game-prototype.html`（v3.2）と `world-editor.html` の原文を切り出し、`src/game/` と `src/editor/` へ配置。
- 既存のHTMLはそのまま保持。分割を結合すると元HTMLと完全一致する設計。
- `scripts/build.mjs`：Node.js標準機能のみで再結合。 `--check` で生成結果と完成HTMLの厳密一致を検証。
- `scripts/test-build.mjs`：構文、共通港湾ブロックの一致、基本仕様の静的回帰チェック。
- `docs/`：プロジェクトルール、ゲーム仕様、ワールド仕様、引き継ぎ、更新履歴。
- 未検証：分割ビルドのGitHub Actions実行、Android実機挙動、レンダリングFPS。**分割作業でゲーム機能は修正していない。**
