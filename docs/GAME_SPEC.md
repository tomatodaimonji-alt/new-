# PINE ゲーム仕様（コード確認に基づく）

## ジャンル・世界観
文明機能の停止後、以前からの住民の区域、避難民のテント密集地、軍の臨時司令部、検問所、自然、漁港と軍補給港が共存するPINE島。島の外に海と本島都市がある。ゾンビ世界観を保ち、探索と発見を中心にする。

## 現在の実装状態（2026-11-17 時点）
- ゲームの主ファイルは `forest-game-prototype.html`。ワールドエディターは `world-editor.html`。
- 起点は旧64×64の市街地を96×96のPINE島へ移したもの。新しいマップは320×160の座標空間に、PINE島、海峡、本島を共存させる。
- 島のホテル、スーパー、家屋、多階建て室内、石橋、木橋、旧漁港、軍補給港、避難民の区域。
- 海峡の船は十字キーで操船し、既定の桟橋で乗り降りできる試作。船員、AI運航、兵士の上陸作戦は未完成。
- 本島には簡易道路と住宅風建物が自動生成される。大規模なリアル都市の完成版ではない。
- カメラ周辺の16×16単位のチャンク窓で描画する。**描画用の分割であり、完全な非同期チャンク読み書きは未実装**。
- 位置・向き・ズーム等はlocalStorageに保存。世界データJSONのエディター入出力も残る。

## 入力・描画
Android横画面・大きい十字キー・押しっぱなし移動・調べる/攻撃・視点回転・2本指ズーム。3D WebGL描画、WebAudio音声、外部依存なし。UIは半透明が基本。

## 建築物と地形
家屋は1マスごとの床、壁、扉、窓、屋根。扉を介して屋内外を移動し、屋根・上階表示を切り替える。河川や海は通常歩行不可。橋・岸壁の歩行面と岸の段差を接続する必要がある。

## 将来予定（未完成）
本島の密度・施設・港湾の景観の充実、船の航路や複数船、兵士の実際の行進・乗船・上陸、チャンク単位のオブジェクト永続化・LOD、Android実機での継続性能評価。

## 既知のリスク
白い石橋の見た目と通過判定は過去に繰り返し回帰した。新設港の桟橋接続と船の乗下船を含め、コード上の静的チェックだけで「実機修復完了」と断定しないこと。


## ビジュアル品質・現実に根ざした世界
PINEの世界は、機能を満たすだけの記号的な立方体ではなく、実際の生活や建築の理由が見える景観を目指す。建物・港・橋・小物・道路・乗り物・自然物の形状と配置は、現実の写真・資料と参考ゲーム画像から構造・素材・比率・経年変化を理解し、独自に作り込む。危機下の避難民キャンプ、旧住民街、軍臨時基地で施設・物資・施工方法の違いを表現する。

詳しい制作・完成判定は `docs/ASSET_QUALITY_STANDARD.md`、参考資料は `docs/ASSET_REFERENCE_LOG.md` に記録する。
