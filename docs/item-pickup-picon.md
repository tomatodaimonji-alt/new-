# 「ピコン」 item acquisition confirmation
A short original two-note cue made offline for World Workshop, replacing the earlier recorded bag cloth via the same cached itemPickup buffer. Pitches 587.33 Hz then 783.99 Hz, with a little soft harmonic color and rounded envelopes. 24 kHz signed PCM16LE, 3,720 samples / 155 ms, peak 0.44 before original 0.60 playback gain. Ground footstep separation remains 68 ms; chest transfer has no step delay. Plays only after the existing successful inventory write. Gold/coin, enemy loot, dropping, healing, other UI, and mix/SE settings are untouched.
