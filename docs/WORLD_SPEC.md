# PINE ワールドと座標系

## 絶対ルール
PINE島・海・本島のワールド切替はしない。単一の `x,z,y` 座標と共通の描画・移動・当たり判定で扱う。チャンク境界はプレイヤーから不可視にする。

## 現行レイアウト（実装上の概要）
- マップ全体: 320×160、旧PINE島: x=0..95 / z=0..95。元のマップを+16移した建物と地形。
- 海峡: 島の東方向、概ね x=96..155。
- 本島: 概ね x>=156（海岸の輪郭には座標による揺らぎがある）。
- 描画チャンク: 16×16。カメラ近傍を範囲選択して描画更新。
- 初期の旅客港: PINE島東側 x≈86..100, z≈55..59。本島港 x≈145..164, z≈55..59。船のルートは概ねその間。
- 旧市街・農地・河川・白い石橋は既存の編集データにあり、港・軍施設の追加処理より優先する。

## 区域ごとの意味
PINE島: 旧住民・住宅、畑、避難民キャンプ、軍臨時司令部、検問所、ホテル、スーパー、旧漁港、軍補給港、松林と海岸。
本島: インフラの機能停止した都市・港湾。現実的な街区の規模と連続性を目標とする。

## 港と橋
- 旧白い石橋は `bridgeStone` / `bridgeStoneEnd` の連続構造。単一橋面の高さ、幅3マス、南北の岸との歩行接続を守る。
- 木造桟橋・コンクリート岸壁は `pineHarborPier` / `pineHarborQuay`。係留・照明・積荷の景観ブロックをエディターとゲームで共有。
- 船は桟橋の上に描かない。港から船へ乗り、海上を移動して港へ接岸後に降りる。
- 新施設の固定座標上書きは禁止。既存住宅、作物、柵、道路、足場を確認する。

## チャンクと永続化
描画の外にある地物を即時破棄することと、ゲームデータを削除することを混同しない。遠方の未描画チャンクも同じワールドの一部。現在の実装は座標ベースの本島地面生成と描画窓であり、変更・破壊状態のチャンク永続化と非同期ストリーミングは未完成。
